# Écorché athlétique — asset de validation

[Rapport, limites et rendus](../../M4A_ECORCHE_RECONSTRUCTION_ATHLETIQUE.md).

- `source.glb` : original fourni, inchangé.
- `ecorche-athletique.blend` : source, reconstruction symétrique, version athlétique,
  démo pectoral orange, paramètres réversibles et rig de rendu.
- `ecorche-athletique.glb` : version athlétique exportée, pièces séparées.
- `construction.json` : correspondance des pièces, paramètres et limites.
- `export.json`, `verification.json` : mesures du fichier et contrôles.
- `renders/` : rendus Blender bruts, planches de comparaison, métadonnées SHA-256.
