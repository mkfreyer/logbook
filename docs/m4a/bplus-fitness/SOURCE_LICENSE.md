# Blender Studio Human Base Meshes v1.4.1 — éléments effectivement évalués

Archive officielle :
https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip

Les deux collections choisies dans le fichier réel déclarent `license: CC0` :

- `Body Male - Realistic`, auteur **Dan Ulrich**, corps et deux yeux.
- `Body Male - Stylized`, auteur **Julien Kaspar**, corps basé sur Snow et deux yeux.

Le bloc texte `README` intégré au `.blend` indique également que les assets
fournis sont dans le domaine public sous CC0. Les déclarations originales et
les métadonnées des collections sont conservées dans [inventory.json](inventory.json).
[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/) permet adaptations
et redistribution commerciale ; ces fichiers restent ici des sources d'étude.

Le fichier contient aussi un bloc texte `License` attribuant le **Rain Rig** sous
CC BY 4.0 à Blender Foundation / cloud.blender.org. Cette mention est conservée,
sans l'effacer ni l'étendre aux corps dont les collections déclarent CC0.
Aucun rig, asset Rain ou code embarqué n'est chargé dans les rendus comparatifs.
L'exécution automatique des scripts Blender est désactivée.

Seules les géométries des six objets nommés dans l'inventaire sont rendues.
Leurs matériaux sont remplacés par le satin commun, leurs proportions et leur
pose native sont conservées. Aucun fichier du bundle n'est intégré à Logbook.
