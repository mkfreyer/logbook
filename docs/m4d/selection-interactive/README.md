# Captures et contrôles M4D-A

Voir le [rapport](../../M4D_A_SELECTION_INTERACTIVE.md) et le [guide iPhone/PowerShell](../../M4D_A_GUIDE_IPHONE_WINDOWS.md).

Les PNG `selection-*` sont des captures réelles du visualiseur Three.js local (Chromium logiciel, viewport 430 × 760, facteur 1). Une seule zone orange par capture ; les autres sont neutres. `planche-huit-selections.png` assemble leurs recadrages, sans retoucher les pixels du mannequin. L’interface React Native et le fonctionnement sur un iPhone réel attendent le test utilisateur.

`browser-verification.json` décrit les touchers et sélections M4D ; `viewer-regression.json` décrit les gestes et cinq cycles de libération du moteur. `verification.json` donne les empreintes des ressources protégées et les résultats des contrôles. Les journaux `.txt` gardent les sorties des vérifications locales.
