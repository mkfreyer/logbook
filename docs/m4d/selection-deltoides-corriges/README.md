# Nouvelles sélections des deltoïdes

[Rapport de livraison](../../M4C_M4D_DELTOIDES_CORRIGES.md) · [Guide iPhone](../../M4D_A_DELTOIDES_CORRIGES_IPHONE.md).

Les PNG sont de vrais rendus du visualiseur local dans Chromium/SwiftShader, viewport 430 × 760. La planche assemble leurs recadrages. Il ne s’agit pas de nouvelles captures iPhone. Les résultats JSON documentent les huit touchers, les gestes, la réinitialisation et le nettoyage. La nouvelle répartition attend la validation utilisateur.
